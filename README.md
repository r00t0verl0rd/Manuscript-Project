# Manuscript Project

Демо‑веб‑страница с «неоновой» атмосферой и лентой идей (для людей и для роботов). Проект стилизован на CSS (включая матовое стекло, неоновые эффекты, адаптив под мобильные), а фон — анимация **particles.js**.

> ⚠️ В текущей версии работа с блокчейном/ончейн‑частью (mint/голосование) отключена: интерфейс работает как демо.

## Что внутри

- **index.html** — структура страницы: навигация, подключение кошелька и адаптивная лента идей.
- **script.js** — демо‑логика: навигация, безопасная отрисовка идей, сортировка и заглушки действий.
- **i18n.js** — загрузка YAML-каталогов и переключение языка без перезагрузки страницы.
- **locales/ru.yml** и **locales/en.yml** — переводы интерфейса, описаний и демо-идей.
- **styles.css** — основной стиль: неоновый/киберпанк-дизайн, карточки, кнопки и анимации.
- **particles-config.js** — настройка фона particles.js.

## Функциональность

### Языки интерфейса

В шапке доступен переключатель **RU / EN**. При запуске `i18n.js` загружает `locales/ru.yml` и `locales/en.yml` через `js-yaml`, а тексты подменяются на лету через `data-i18n`. Для работы `fetch` нужен локальный HTTP-сервер; открытие `index.html` напрямую может быть заблокировано браузером.

### Лента идей

Идеи распределяются по трём колонкам на широких экранах и по двум на мобильных. Демо-список сортируется по количеству поддержавших или дате создания.

### Подключение кошелька и голосование

Кнопки присутствуют в демонстрационном интерфейсе, но блокчейн-функции пока отключены. При попытке выполнить действие показывается локализованное уведомление.

## Установка и запуск

Так как проект — статический, запустить можно локально в браузере.

1. Откройте `index.html` в браузере.
2. Лента и части интерфейса загрузятся автоматически.

Также можно быстро запустить локальный сервер (если используете, например, VS Code Live Server).

## Используемые технологии
